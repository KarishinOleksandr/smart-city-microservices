# Smart City Microservices Architecture

Розподілена система мікросервісів для збору, обробки та зберігання телеметрії в середовищі "розумного міста" (Smart City).

## Архітектура

Система складається з незалежних сервісів:
- **IoT Ingestion Service** (порт 8001): вхідний шлюз для прийому телеметрії від сенсорів міста.
- **Processing & Rules Service** (порт 8002): сервіс комплексного потокового аналізу та генерації сповіщень про перевищення нормативів (якість повітря, затори).
- **Storage Service** (порт 8003): сервіс розподіленого збереження даних із підтримкою схеми партиціонування Azure Cosmos DB (`/district_id`).
- **Sensor Simulator**: автономний емулятор сенсорних пристроїв 5 міських районів.

## Запуск через Docker Compose

```bash
docker compose up --build
```

## Локальний запуск без Docker

```bash
python run_local.py
```
